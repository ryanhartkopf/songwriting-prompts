# SMS Opt-In Evidence — Songwriting Prompts

Documentation of the consent flow for A2P 10DLC campaign review.

## How Consent Is Collected

1. The Brand owner shares the campaign phone number directly, one-on-one, with a small number of individuals who have personally requested access. The number is not published or advertised anywhere public.
2. The end user sends the keyword **START** or **SUBSCRIBE** to that number by SMS.
3. The system replies with an automatic confirmation message, shown below, which restates the program name and how to get help or opt out.
4. Once opted in, the user receives one songwriting prompt message per day.

## Example Message Exchange

**User texts:**
> SUBSCRIBE

**Automatic reply:**
> Songwriting Prompts: You are now opted-in. For help, reply HELP. To opt-out, reply STOP.

**Later, daily prompt:**
> Pick an object in your room and write a verse about it without ever saying its actual name.

**If user texts HELP:**
> Reply STOP to unsubscribe. Msg&Data Rates May Apply.

**If user texts STOP:**
> You have successfully been unsubscribed. You will not receive any more messages from this number. Reply START to resubscribe.

## Program Details

| | |
|---|---|
| **Message frequency** | Up to one message per day |
| **Message & data rates** | May apply |
| **Opt-in keywords** | START, SUBSCRIBE |
| **Opt-out keywords** | CANCEL, QUIT, STOP, OPTOUT, UNSUBSCRIBE, STOPALL, REVOKE, END |
| **Help keywords** | HELP, INFO |
